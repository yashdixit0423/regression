# 📊 Logistic Regression

## 🚀 Overview

It includes hands-on implementations to understand how probabilities are used to classify data into different categories.

---

## ⚙️ How It Works  
Logistic Regression predicts the **probability** that a data point belongs to a particular class using the sigmoid function:

**P(y = 1) = 1 / (1 + e^-(mx + c))**

Where:  
- `P(y = 1)` → Probability of class 1  
- `x` → Input feature  
- `m` → Weight (coefficient)  
- `c` → Bias (intercept)  

The output is then converted into a class label using a threshold (usually 0.5).
