## ⚙️ How It Works  
Linear Regression models the relationship between independent variables (features) and a dependent variable (target) by fitting a best-fit line:

**y = mx + c**

Where:  
- `y` → Dependent variable  
- `x` → Independent variable  
- `m` → Slope of the line  
- `c` → Intercept  

The model minimizes the error between predicted and actual values.
